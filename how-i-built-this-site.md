This page documents the site-building process so readers can understand the tool stack and design choices.

## Tool stack and layout

- Built with **Jekyll** for static-site generation.
- Configured for **GitHub Pages** publication.
- Structured with a shared layout, accessible navigation, and reusable styling variables.
- Includes a dedicated `assets/images/` folder for content images.

## Accessibility choices

- Semantic landmarks (`header`, `nav`, `main`, `footer`).
- ARIA labels for key regions.
- Skip link for keyboard users.
- High-contrast focus styles.

## Agent involvement

An AI coding agent scaffolded this structure, generated starter page copy, set up the GitHub Actions workflow, and prepared documentation so the site owner can focus on writing and revising final content.
